# Nor Afiqah — Developer Portfolio

A responsive single-page developer portfolio, designed for **fiqahcaa.github.io**.

## Getting started

Open `index.html` in a web browser. No installation or build tools needed.

## Publish with GitHub Pages

1. Open the `fiqahcaa.github.io` repository on GitHub.
2. Click **Add file → Upload files**.
3. Upload `index.html`, `style.css`, and `script.js` (and later your images folder). **Extract the ZIP first**; don't upload the ZIP itself.
4. Click **Commit changes**.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**, then **main** and **/(root)**, and save.
7. Your site should be available at `https://fiqahcaa.github.io/` when publishing finishes.

## Customize

- Edit text in `index.html`.
- Change colors in the CSS variables at the top of `style.css`.
- Replace project summaries and screenshot paths in the `projects` object near the bottom of `script.js`.
- To use an approved screenshot, create an `images` folder, add the image, then set e.g. `image: 'images/risk-assessment.png'` for that project.
- Add your LinkedIn/email later when you're comfortable making that information public.

## Privacy

Some featured projects relate to internal organizations. The mock dashboards on project cards are **illustrations, not actual screenshots**. Only upload screenshots, datasets, URLs, or source code if you have permission and have removed personal, confidential, or security-sensitive information.
